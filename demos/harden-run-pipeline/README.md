# Demo: run-pipeline + harden-pipeline (workshop edition)

Stub — due 26 August 2026.

The reproducibility arc: producer notebooks run to completion against a
manifest (`/run-pipeline`), then an iterative verification loop hardens
every registered output (`/harden-pipeline`). Ships as a portable
workshop edition with a small self-contained analysis project
(manifest, notebooks, data) so it runs from this folder on any machine.

Starter version: the two-line variant you can run on your own project
today (documented here alongside the full demo).
