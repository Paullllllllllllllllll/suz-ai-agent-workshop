# Demo: literature-pipeline + zotero-curator (workshop edition)

Stub — due 26 August 2026. Backup demo.

End-to-end literature processing (select, transcribe, summarize,
deep-read, condense into an overview table) plus Zotero curation.

sample of open-access papers; no external tools required. For wiring
the full version to your own Zotero library, see
