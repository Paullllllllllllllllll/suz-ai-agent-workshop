# Morning Walkthrough — Handout

Stub — full script due 26 August 2026.

Step-by-step script for the morning session, mirroring what happens on
the beamer: every prompt, every command, and the expected outcome, for
both Claude Code (CLI) and the Claude Desktop app. Doubles as the
catch-up document for anyone who missed the morning.

The walkthrough arc:

1. Project setup: `CLAUDE.md`, custom skills, rules, and subagents.
2. Subagents read and analyze the paper set in `project/papers/`.
3. The agent fetches a dataset live from a public API into
   `project/data/`.
4. A quick exploratory analysis with a robustness check, documented by
   the agent.
5. `/grill-me` to stress-test the design, then a written analysis plan.
