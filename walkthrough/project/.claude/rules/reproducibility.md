# Reproducibility

- Every figure and table must be reproducible from a script in this
  project. No result may exist only in a chat transcript or a manually
  assembled file.
- Every script states its data sources at the top: which file or
  endpoint, matching the entries in `data/README.md`.
- No manual edits to data files. All cleaning, filtering, and reshaping
  happens in scripts, so the path from raw data to result stays
  inspectable.
