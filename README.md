# SUZ AI Agent Workshop v0.1.0

Materials for the one-day workshop "AI Agents for Social Science
Research" at the Department of Sociology (SUZ), University of Zurich.

Date: Tuesday, 8 September 2026, 9:00-17:00 (door opens 8:30).
Facilitators: Paul Götz and Nico Mutzner.

## Programme

| Time  | Block                                                     |
|-------|-----------------------------------------------------------|
| 8:30  | Door opens; setup help desk                               |
| 9:00  | LLMs, CLIs, and coding agents (type-along)                |
| 10:00 | Guided walkthrough: one research workflow, CLI + Desktop  |
| 12:15 | Lunch                                                     |
| 13:15 | Synthetic dataset, generated live                         |
| 13:40 | Advanced workflow demos                                   |
| 14:30 | Hands-on in tracks (pipelines, quant, literature)         |
| 16:30 | Share round, responsible use, feedback                    |
| 17:00 | End                                                       |

## Quick start (before the workshop)

1. Follow the install guide for your system: `install/windows.md` or
   `install/macos.md`. Do this before 8 September; it takes about
   20 minutes and needs a Claude account.
2. Clone this repository:

   ```bash
   git clone https://github.com/Paullllllllllllllllll/suz-ai-agent-workshop.git
   ```

3. Bring your laptop and, if you have one, a small project or dataset
   of your own for the afternoon.

## Repository layout

```text
install/       setup guides (Windows, macOS; Claude Code CLI + Desktop)
walkthrough/   morning: step-by-step handout and the toy project
demos/         afternoon: workshop editions of advanced skills
tryouts/       afternoon: starter packages per hands-on track
catchup/       added after the workshop for those who missed it
```
