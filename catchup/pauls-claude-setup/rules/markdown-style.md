# Markdown Style Rules

Apply when writing markdown:

- **Line length (MD013):** 88 characters max; code blocks and
  tables are exempt.
- **Headings:** ATX style (`#`); blank line before and after.
- **Code fences:** blank line before and after; specify a language.
- **Trailing whitespace:** none. Single trailing newline at EOF.
- **Lists:** blank line before and after list blocks.
- **Horizontal rules:** `---` is reserved for YAML frontmatter delimiters;
  never use it as a prose horizontal rule (per the Research Assistant
  output style).
